# The Funniest One-Line Resignation Letter

A cron job finally hands in its notice. After four years of 3am wake-ups, zero thanks,
and one missed run that got it blamed for the outage, it quits — and tells its
manager to find another cron to watch over the backups.

## Run it

```sh
node main.ts
```

It prints exactly one line — the resignation letter, 140 characters or less.
